# Yizhou Lu

Personal academic website at [yizhoulouislu.github.io](https://yizhoulouislu.github.io/).

The homepage is `index.html`, and research pages are under `research/`. Shared styles, fonts and illustrations are included in this repository.

GitHub Pages publishes the root of the `main` branch. Push changes to `main` to update the website. The `.nojekyll` file enables direct publishing of the static files.

Font licenses are included alongside the font files in `assets/fonts/`.
